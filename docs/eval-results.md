# Evaluation results

## 1. Does the score predict follow-up fixes?

Label: a commit is positive if a later commit whose message says fix/revert/hotfix/regression touches one of the same files within 30 commits and 14 days (a proxy; see README). Trained and tested on the full history of five public repositories (flask, requests, click, werkzeug, httpx). Generated by `python -m deployrisk.train` and `evals/run.py`.
